## ✨ Возможности

### 🌐 Публичный сайт (`index.html`)
- **Hero-секция** с анимацией и ключевыми бейджами
- **Биография врача** с описанием опыта и достижений
- **Образование и квалификация** — карточки с дипломами
- **Опыт в цифрах** — анимированные счётчики (12+ лет, 4000+ пациентов)
- **Специализация** — дерматология, косметология, трихология
- **Публичное расписание** на неделю с онлайн-записью
- **Форма записи на приём** с сохранением в `localStorage`
- **Философия врача** — цитата и принципы работы
- **Контакты** — телефон, email, адрес, часы приёма

### 🔐 Кабинет врача
**`login.html`** — авторизация с сессией
**`admin.html`** — полноценная панель управления:

- 📊 **Дашборд** с KPI-метриками и последними заявками
- 📋 **Заявления** с фильтрацией по статусам (новые/подтверждённые/отменённые)
- 👥 **База пациентов** с поиском, фильтрами и полными картами
- 📅 **Управление расписанием** — блокировка/разблокировка слотов
- 📥 **Экспорт пациентов в CSV**
- 🔔 **Toast-уведомления** и модальные окна

## 🚀 Быстрый старт

### 1. Клонирование репозитория

```bash
git clone https://github.com/ВАШ_ЛОГИН/clinic-shumilovskaya.git
cd clinic-shumilovskaya
```

### 2. Запуск локально

Поскольку проект использует `localStorage`, достаточно открыть `index.html` в браузере:

```bash
# Просто откройте файл
open index.html       # macOS
start index.html      # Windows
xdg-open index.html   # Linux
```

Или запустите локальный сервер (рекомендуется):

```bash
# Python 3
python -m http.server 8000

# Node.js (если установлен)
npx serve .
```

Затем откройте [http://localhost:8000](http://localhost:8000)

### 3. Демо-доступ в кабинет

| Поле | Значение |
|------|----------|
| **Логин** | `doctor` |
| **Пароль** | `1234` |

## 💾 Хранение данных

Проект работает **без бэкенда** — все данные хранятся в `localStorage` браузера:

| Ключ | Содержимое |
|------|-----------|
| `clinic_requests_v1` | Заявки с формы записи |
| `clinic_patients_v1` | База пациентов |
| `clinic_schedule_blocks_v1` | Заблокированные слоты |
| `clinic_session_v1` | Флаг авторизации |

⚠️ **Внимание:** данные не синхронизируются между устройствами и могут быть очищены при сбросе браузера.

## 🌍 Деплой на GitHub Pages

1. Загрузите проект в репозиторий на GitHub
2. Перейдите в **Settings → Pages**
3. В разделе **Source** выберите:
   - **Branch:** `main`
   - **Folder:** `/ (root)`
4. Нажмите **Save**
5. Через 1-2 минуты сайт будет доступен по адресу:
   ```
   https://ВАШ_ЛОГИН.github.io/clinic-shumilovskaya/
   ```
